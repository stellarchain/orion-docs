## Complete Summary Table

| Error Code (`type`) | HTTP Status | Title | Description |
| :--- | :---: | :--- | :--- |
| [`bad_request`](/horizon-errors/bad_request) | `400` | Bad Request | The request you sent was invalid in some way (e.g. malformed query parameter, invalid cursor, invalid asset format, or out-of-range limit). |
| [`before_history`](/horizon-errors/before_history) | `410` | Data Requested Is Before Recorded History | The requested ledger or cursor predates the earliest ledger retained by this instance. |
| [`client_disconnected`](/horizon-errors/client_disconnected) | `499` | Client Disconnected | The client closed the HTTP connection before the server finished sending the response. |
| [`forbidden`](/horizon-errors/forbidden) | `403` | Forbidden | The client is not authorized to access the requested resource. |
| [`invalid_accounts_params`](/horizon-errors/invalid_accounts_params) | `400` | Invalid Accounts Parameters | The `/accounts` collection endpoint requires exactly one filter parameter (`signer`, `sponsor`, `asset`, or `liquidity_pool`). |
| [`invalid_order_book`](/horizon-errors/invalid_order_book) | `400` | Invalid Order Book Parameters | The parameters specifying the SDEX order book pair (`/order_book`) are missing or invalid. |
| [`method_not_allowed`](/horizon-errors/method_not_allowed) | `405` | Method Not Allowed | The HTTP method used is not supported for this endpoint. |
| [`not_acceptable`](/horizon-errors/not_acceptable) | `406` | An acceptable response content-type could not be provided for this request | The client requested a media type in the `Accept` header that the server cannot produce. |
| [`not_found`](/horizon-errors/not_found) | `404` | Resource Missing | The requested URL route, account, ledger, transaction, operation, offer, liquidity pool, or claimable balance does not exist. |
| [`not_implemented`](/horizon-errors/not_implemented) | `404` | Resource Not Yet Implemented | The requested URL is planned but not yet implemented. |
| [`not_supported`](/horizon-errors/not_supported) | `400` | Not Supported | The requested feature or parameter combination is not supported. |
| [`rate_limit_exceeded`](/horizon-errors/rate_limit_exceeded) | `429` | Rate Limit Exceeded | The client has sent too many requests in a given time window. |
| [`resource_limit_exceeded`](/horizon-errors/resource_limit_exceeded) | `422` | Resource Limit Exceeded | The query exceeded the server's scan/work budget or member fanout limit. |
| [`server_error`](/horizon-errors/server_error) | `500` | Internal Server Error | An unexpected internal error occurred while processing the request. |
| [`server_over_capacity`](/horizon-errors/server_over_capacity) | `503` | Server Over Capacity | The server is temporarily overloaded and cannot accept additional concurrent work. |
| [`service_unavailable`](/horizon-errors/service_unavailable) | `503` | Service Unavailable | The request cannot be serviced at this time because a required subsystem is warming up or temporarily unreachable. |
| [`stale_history`](/horizon-errors/stale_history) | `503` | Historical DB Is Too Stale | The node's ingested history is lagging behind the Stellar network tip beyond the configured staleness threshold. |
| [`still_ingesting`](/horizon-errors/still_ingesting) | `503` | Still Ingesting | Data cannot be presented because initial state or order book ingestion is still in progress. |
| [`timeout`](/horizon-errors/timeout) | `504` | Timeout | The request or transaction submission timed out before completing. |
| [`transaction_failed`](/horizon-errors/transaction_failed) | `400` | Transaction Failed | The transaction was well-formed XDR, but Stellar Core rejected it or one of its operations failed during execution. |
| [`transaction_malformed`](/horizon-errors/transaction_malformed) | `400` | Transaction Malformed | The `tx` parameter could not be decoded as a valid base64-encoded Stellar `TransactionEnvelope` XDR structure. |
| [`transaction_submission_timeout`](/horizon-errors/transaction_submission_timeout) | `504` | Transaction Submission Timeout | The transaction submission timed out waiting for ledger inclusion. |
| [`unsupported_media_type`](/horizon-errors/unsupported_media_type) | `415` | Unsupported Media Type | The request `Content-Type` header is not supported by this endpoint. |
